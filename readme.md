# Visor Desktop

Asistente visual ligero para computador que analiza la ventana activa y entrega soluciones inmediatas.

## Descripción

Visor Desktop es una herramienta diseñada para asistir al usuario mientras trabaja en su computador. Cuenta con una arquitectura modular interna que permite clasificar consultas, revisar datos locales y agilizar la toma de decisiones.

## Estructura del proyecto

El aplicativo se compone de los siguientes archivos:

- index.html: Interfaz del visor flotante con enlace oficial a Bootstrap y elementos con nombres en español separados por espacio.
- style.css: Hoja de estilos moderna, oscura y translúcida, empleando fuentes del sistema operativo.
- script.js: Lógica modular interna que coordina la captura, el triaje y el portapapeles.
- readme.md: Documentación básica del proyecto.

## Uso del aplicativo

- Abrir el archivo index.html en cualquier navegador del computador.
- Dar clic en el botón Capturar pantalla para simular la revisión de la ventana activa.
- El visor evaluará la dificultad y mostrará la solución sugerida en pantalla.
- Dar clic en Copiar solución para pasar el texto al portapapeles del computador.

## Reglas de desarrollo

- Uso de JavaScript clásico nativo.
- Clases e identificadores en español separados por espacios normales.
- Léxico adaptado al contexto local colombiano.
- Sin librerías externas pesadas ni fuentes de terceros.
